# Drift
A puzzle game where you place magnets to guide a ball to the end. Once the simulation start, you can only remove magnets and not add new ones.

# Features
* Magnetic forces (repulsion and attractions)
* Circle to circle collision and circle to tine collisio
* Mouse controls
* Levels Based system

# How to play
Just visit https://mohammedmostafawebdeveloper.github.io/Drift/ or download this repo and open index.html file in your browser

# Rules
* Before clicking the start button, you are allowed to add magnets by click the screen
* The edit mode is changed from the tools bar at the tool (add attractive magnet, add repulsive magnet, remove magnet)
* Try to place the magnets so that they guide the ball to the finish
* Once you click start, the ball starts moving and you can only click to remove magnets
* If the ball is inside the finish, it stays there and you win this level
* Move on to the next level after that
